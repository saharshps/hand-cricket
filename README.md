# 🏏 Hand Cricket Game

A simple web-based Hand Cricket game built using HTML, CSS, and JavaScript.

## 🚀 Live Demo
👉 https://saharshps.github.io/hand-cricket/

## 📌 Features
- Play hand cricket against computer
- Random computer moves
- Score tracking
- Simple and responsive UI

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 📂 Project Structure
hand-cricket/
│── index.html
│── style.css
│── scripts.js

## 🎯 Purpose
This project was built to practice JavaScript logic and DOM manipulation.
